# Voice PDF Chatbot Using Gemini AI

It is a Streamlit-based RAG application that facilitates interaction with PDF documents by extracting text and providing responses to user questions. The application utilizes the capabilities of the Google Generative AI model (Gemini) for question answering and uses the FAISS library for efficient text embedding similarity search.

The application also supports voice-based interaction, allowing users to ask questions using voice. The AI response can be played back as voice, and the answer is also transcribed and displayed on the screen.

## Introduction

This project offers a user-friendly interface for engaging with PDF documents. Users can upload PDFs, extract text, and ask questions about the content. The application provides accurate and detailed responses generated by the Gemini AI model.

In addition to text-based queries, users can interact with the PDF content through voice. Users can speak their questions, receive voice responses, and view the transcribed answer on the screen, making the application more interactive and accessible.

## Description

The application executes the following core functionalities:

- **PDF Uploading**: Users can upload multiple PDF files via the application interface, enabling seamless access to various documents.
- **Text Extraction**: Text extraction is performed on each page of the uploaded PDFs, ensuring comprehensive access to document content.
- **Text Chunking**: Extracted text is segmented into manageable chunks for streamlined processing, enhancing efficiency in subsequent tasks.
- **Text Embeddings**: Utilizing Google Generative AI Embeddings, embeddings for the text chunks are generated, facilitating semantic understanding and analysis.
- **Similarity Search**: FAISS, a library renowned for its speed in similarity search, is employed to swiftly locate text chunks relevant to user queries.
- **Question Answering**: A conversational AI model powered by Gemini generates responses to user questions based on the content of the uploaded PDFs, enriching the interactive experience.
- **Voice-Based Question Asking**: Users can ask questions through voice instead of typing manually.
- **Speech-to-Text Transcription**: The spoken question is converted into text so it can be processed by the application.
- **Voice Response Output**: The generated answer can be converted into speech and played back to the user.
- **On-Screen Answer Display**: The AI-generated answer is also transcribed and displayed on the Streamlit interface for easy reading and reference.

This project combines natural language processing, machine learning, speech processing, and retrieval-augmented generation to enable dynamic exploration of PDF documents through both text and voice-based interactions.

## Libraries & Frameworks

- **Google Generative AI (Gemini)**: For providing powerful capabilities in text understanding and answer generation.
- **FAISS Library**: For enabling efficient similarity search of text embeddings.
- **Streamlit**: For simplifying the development of interactive web applications.
- **LangChain**: For providing the framework to utilize the Large Language Model.
- **Speech Recognition / Speech-to-Text Library**: For converting user voice questions into text.
- **Text-to-Speech Library**: For converting Gemini-generated answers into voice responses.

## Key Features

- Upload and process multiple PDF files.

## Installation and usage

1. Clone Shashank's repository and enter the project directory:

```bash
git https://github.com/contactshashank/PDFVoiceBot.git
cd PDFVoiceBot
```

2. Create and activate a virtual environment.

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS or Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Install the dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

4. Copy `.env.example` to `.env` and add your own Gemini API key:

```dotenv
GOOGLE_API_KEY=your_actual_google_api_key
```

Never commit or upload the `.env` file.

5. Run the application:

```bash
python -m streamlit run main.py
```

6. Open `http://localhost:8501`, upload PDF files, select **Process PDFs**, and ask questions using text or the microphone.
